# Changelog

Group entries under `Added`, `Changed`, `Fixed`, and `Removed`. Skip sections
that would be empty, and keep one line per user-visible change.

- Lead with the effect on the user, not the implementation.
- Name the module or command that changed.
- Never invent a change that is not in the diff.
